Аналитический проект по оптимизации товарного портфеля британского
интернет-магазина подарков. Цель — оценить структуру ассортимента
и предложить список SKU-кандидатов на сокращение с оценкой рисков.

## 📋 Бизнес-задача

Руководство магазина рассматривает сокращение ассортимента на **~20%**.
Задача: оценить риски такого решения и найти SKU-кандидаты, которые
действительно можно безопасно вывести из ассортимента.

## 📊 Данные

- **Источник:** [Online Retail II (UCI ML Repository)](https://archive.ics.uci.edu/dataset/502/online+retail+ii)
- **Период анализа:** 01.12.2009 — 30.11.2011 (24 полных месяца)
- **Объём сырых данных:** 1 067 371 транзакция, 5 305 SKU, 5 942 клиента
- **После очистки:** 1 008 431 строка, 4 722 SKU, £19 322 150 выручки

### Скачивание данных

Датасет **не включён** в репозиторий из-за размера (43 MB).

1. Откройте [Online Retail II (UCI)](https://archive.ics.uci.edu/dataset/502/online+retail+ii).


## 📈 Ключевые результаты

### 1. Принцип Парето подтверждается

21.9% SKU (1 034 из 4 722) дают 80% выручки. Классическая структура для ритейла.

### 2. Сезонность ярко выражена

Пики в ноя-дек (Рождество), спады в янв-фев. Паттерн повторяется год к году — сезонность реальная, не случайность.

### 3. Матрица ABC/XYZ

| Группа          | SKU   | % SKU  | Выручка | % выручки |
|-----------------|-------|--------|---------|-----------|
| AX + AY (ядро)  | 519   | 11.0%  | £9.78M  | 50.6%     |
| AZ (риск)       | 515   | 10.9%  | £5.68M  | 29.4%     |
| BZ + CZ (хвост) | 3 270 | 69.2%  | £3.11M  | 16.1%     |

### 4. RFM-сегментация

Champions — 21.5% клиентов, 68.5% выручки. At Risk — 13.4% клиентов, £1.32M выручки. Средняя сумма покупок Champions — £9 163 за весь период (не средний чек).

> ⚠️ **Важно:** RFM не покрывает 13.2% выручки (продажи без CustomerID).

### 5. BCG-матрица

Stars — 21% SKU, 55% выручки. Cash Cows — 29% SKU, 42% выручки. Dogs — 37% SKU, только 2.4% выручки.

> ⚠️ **Важно:** снижение выручки на 8.1% относится только к товарам, продававшимся в обоих периодах. По всему ассортименту выручка выросла на ~6.7%.

### 6. Basket analysis

Проверка связей кандидатов на вывод с топ-100 SKU. Найдены 82 пары для 14 кандидатов с `joint_orders >= 20` и `lift >= 1.5`. Максимальный lift — 23.63 у пары `90059A + 15036`.

406 SKU (96.7% кандидатов) не связаны с топ-100 — безопасны для удаления.

## 💡 Рекомендация

Предлагаем сократить **406 SKU (8.6% ассортимента)** — безопасно.
**14 SKU** — требуют ручной проверки (связаны с топ-100).

| Категория                 | SKU | % SKU   | Выручка  | % выручки | Действие       |
|---------------------------|-----|---------|----------|-----------|----------------|
| Безопасны для удаления    | 406 | 8.60%   | £45 110  | 0.23%     | ✅ Удалять     |
| Требуют ручной проверки   | 14  | 0.30%   | £2 321   | 0.01%     | ⚠️ Проверить   |
| **Всего**                 | 420 | 8.89%   | £47 430  | 0.25%     |                |

**Рычаг: 37x** — доля сокращаемых SKU в 37 раз больше их доли в выручке.

### Путь формирования списка

1. **Начало:** CZ + CY (2 430 SKU).
2. **Умеренный фильтр:** 627 SKU.
3. **Фильтр сезонности:** 207 SKU исключены (пик ноя-дек > 50%) → 420 SKU.
4. **Basket-проверка:** 14 SKU связаны с топ-100 → **406 безопасных**.

### Критерии отбора

- Возраст ≥ 12 мес.
- Клиентская база ≤ 10 (по `COUNT(DISTINCT invoice_no)`)
- Повторные покупки = 0 (по `COUNT(DISTINCT invoice_no)`)
- Активные месяцы ≤ 18
- Не сезонные (пик ноя-дек < 50% выручки)

### Покрытие Customer ID

| Статус                     | SKU |
|----------------------------|-----|
| Client data OK (≥50%)      | 450 |
| Partial client data (10–50%) | 112 |
| No client data (<10%)      | 65  |

178 SKU (28.4%) требуют ручной проверки — слабое покрытие Customer ID.

## ⚠️ Ограничения

- 0.23% выручки — историческая доля. Реальная потеря может быть меньше (клиенты купят аналоги) или больше (потеря клиентов).
- «Рычаг» — это метрика эффективности отбора. Он показывает, что доля сокращаемых SKU в 37 раз больше их доли в выручке. Это не означает денежную экономию и не переводится в формулировку «теряем £1 на каждые £37».
- Продажи ≠ спрос. Out-of-stock искажает данные.
- Нет данных о марже. Часть из 406 SKU могут быть высокомаржинальными.
- Список 406 SKU — кандидаты, требуют ручной проверки менеджером.
- 65 SKU с "no client data" — не удалять автоматически. Ноль в клиентской базе означает «клиентов не удалось идентифицировать», а не «покупателей мало».
- RFM не покрывает 13.2% выручки (продажи без CustomerID).
- Пары в basket-анализе показывают корреляцию, а не причинно-следственную связь.

## 📝 Допущения

- Нормализация SKU: все коды приведены к UPPER (объединено 172 дубликата). Служебные коды очищены после нормализации.
- Отмены (`invoice_no LIKE 'C%'`) исключены из анализа продаж. Подтверждённые отмены (134 пары «покупка → отмена» в течение 60 минут) исключены вместе с положительными записями.
- Дубликаты строк оставлены — повторная покупка одного товара в одном счёте валидна.
- Служебные SKU (POST, DOT, M, ADJUST, gift-сертификаты и др.) исключены — это не товары.
- Сезонные товары (пик ноя-дек > 50% выручки) исключены из финала — их удаление сломало бы новогодний ассортимент.
- Товары без CustomerID оставлены для ABC/XYZ, но исключены из RFM.
- Единый период: 24 полных месяца (01.12.2009 — 30.11.2011). Декабрь 2011 отсечён.
- Повторные покупки считаются по `COUNT(DISTINCT invoice_no)` — разные заказы, а не разные строки.
